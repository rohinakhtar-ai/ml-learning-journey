# Advertising Sales Prediction Using Linear Regression

## Project Overview

This project uses Linear Regression to predict product sales based on
advertising expenditure across different media channels.

The project demonstrates a basic machine learning workflow, including
data exploration, exploratory data analysis, feature selection,
model training, prediction, and model evaluation.

## Dataset

The dataset contains advertising expenditure information for different
media channels and corresponding product sales.

## Workflow

1. Load and inspect the dataset
2. Perform exploratory data analysis
3. Define features and target
4. Split the data into training and testing sets
5. Train a Linear Regression model
6. Make predictions
7. Evaluate the model

## Model Used

- Linear Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## What I Learned

Through this project, I practiced the basic supervised machine learning
workflow and learned how to train and evaluate a Linear Regression model.
